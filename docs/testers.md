# Para quem vai testar

Obrigado por testar. O que você achar, bom ou ruim, me ajuda.

## Onde colocar o código

1. Abra [algory.osmio.tech](https://algory.osmio.tech) e crie a conta (e-mail e senha; chega um código de 6 dígitos no e-mail para confirmar).
2. Vá em **Perfil › Plano e pagamentos › Resgatar código**.
3. Cole o código que você recebeu (formato `XXXXXX-XXXX-XXXX-XXXX`). A tela mostra o que ele libera antes de você confirmar.
4. Confirme. O plano de teste começa na hora, a não ser que o código tenha uma data de início: nesse caso a tela avisa o dia.

## Como o código de teste funciona

- Vale por **3 dias** a partir da ativação (pode variar; a tela mostra).
- Tem um **total de tickets para o período todo**, sem limite por dia. Use como quiser.
- Quando acaba, a conta volta para o plano Grátis. **Nada é apagado.**
- Se você comprar um plano durante o teste, o plano pago começa na hora.

## O que eu vejo do seu uso

Durante o teste eu vejo o **registro de uso** da conta: horário de cada pergunta, qual modelo respondeu, quantos tickets gastou e quanto demorou.
Eu **não** vejo o texto das suas perguntas, as respostas nem os seus dados: nada disso é guardado.

## O que vale testar

- Subir uma planilha de verdade, do jeito que ela está, bagunçada mesmo.
- Fazer as perguntas que você faria a alguém que entende do seu negócio.
- Tentar confundir o assistente. Se ele inventar um número, eu quero saber.
- Usar no celular.

Se não tiver planilha, a tela inicial oferece dados de exemplo.
